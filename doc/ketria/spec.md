## 1. ゲーム概要

3つの属性を使った、じゃんけん型のターン制対戦ゲーム。

一般的な「グー・チョキ・パー」の代わりに、以下の3属性を使用する。

- `FIRE` - 松明の炎
- `STONE` - 石
- `MIST` - 白い霧

各属性には `Lv0〜Lv3` のレベルがあり、同じ属性を使うことでレベルが上昇する。

Lv3では属性ごとに異なる必殺効果を使用できる。

### 1.1 属性ごとの役割

```text
FIRE
攻撃
```

```text
STONE
防御
```

```text
MIST
妨害
```

## 2. 対戦の準備

### 2.1 基本ステータス

#### 2.1.1 プレイヤー

- 初期HP: `200`
- FIRE初期レベル: `Lv1`
- STONE初期レベル: `Lv1`
- MIST初期レベル: `Lv1`

#### 2.1.2 敵

- HPは難易度によって変動
- 各属性の初期レベルは基本 `Lv1`
- プレイヤーと同じレベルシステムを使用する想定

### 2.2 難易度・敵HP

プレイヤーの初期HPは `200`。

敵HPはステージごとに以下とする。

| ステージ | 敵HP |
|---|---:|
| STAGE01 | 150 |
| STAGE02 | 200 |
| STAGE03 | 300 |
| STAGE04（Last） | 500 |

ステージ選択の表示条件は以下とする。

- 初期状態では、`STAGE01〜03` のみ表示し、`STAGE01` のみ選択可能とする
- 未解放の `STAGE02・03` はロック表示とし、選択不可とする
- `STAGE02` は、`STAGE01` をクリアすると解放する
- `STAGE03` は、`STAGE02` をクリアすると解放する
- `STAGE04（Last）` は、`STAGE01・02・03` をすべてクリアすると表示する

### 2.3 ステージ開始時のリセット

各ステージは独立した対戦として扱う。

新しいステージを開始するとき、前のステージの状態は持ち越さず、以下をリセットする。

- プレイヤーHP
- プレイヤーと敵の各属性レベル
- Lv0状態
- MISTによる封印状態
- STONEによるダメージ軽減状態

プレイヤーと敵は、各ステージに設定された初期状態で対戦を開始する。

## 3. 対戦の進行

### 3.1 三すくみ

勝敗関係は以下とする。

```text
       FIRE
      ↗    ↘
STONE  ←  MIST
```

#### 3.1.1 世界観上の意味

| 勝つ属性 | 負ける属性 | イメージ |
|---|---|---|
| FIRE | MIST | 炎が霧を晴らす |
| MIST | STONE | 霧・水分が石を包み、蝕む |
| STONE | FIRE | 石が炎を覆い、封じる |

### 3.2 ターンの基本フロー

1. 敵AIが使用可能な属性から1つを選択し、手を確定する
2. プレイヤーが使用可能な `FIRE / STONE / MIST` から1つ選択する
3. 両者の属性を同時に公開する
4. 三すくみにより勝敗を判定する
5. 勝敗がついた場合は勝者だけが相手にダメージを与える。あいこの場合は両者に10ダメージを与える。このターンに有効なSTONEの軽減効果がある場合は、受けるダメージに適用する
   - Lv1・Lv2の場合は、レベルに応じた通常ダメージを与える
   - FIRE Lv3の場合は、50ダメージを与える
   - STONE Lv3の場合は、30ダメージを与え、次に受けるダメージを半減する効果を付与する
   - MIST Lv3の場合は、20ダメージを与え、次のターンに封印する属性を抽選する
6. 両者が使用した属性を更新する。Lv1・Lv2は1上昇する。Lv3は勝利・敗北ならLv0になり、あいこならLv3を維持する
7. ターン開始時からLv0だった属性について、別の属性を使用していた場合はLv1へ復活させる
8. STONEの軽減効果を適用した側の効果を解除する。MISTの封印を解除し、封印されていた属性のレベルを更新する
9. 次のターンへ進む

敵AIは、プレイヤーが現在のターンの属性を選択する前に手を確定する。
プレイヤーが選択を終えるまで、敵AIの手は公開しない。
敵AIは、現在のターンにプレイヤーが選択した属性を参照できない。

### 3.3 ゲーム終了条件

どちらかのHPが `0以下` になった時点でゲーム終了。

```text
両者のHP <= 0
→ DRAW

プレイヤーHP <= 0、敵HP > 0
→ LOSE

敵HP <= 0、プレイヤーHP > 0
→ WIN
```

## 4. 属性レベル
### 4.1 初期状態

```text
FIRE   Lv1
STONE  Lv1
MIST   Lv1
```

### 4.2 レベルアップ

Lv1またはLv2の属性を使用すると、勝利・敗北・あいこにかかわらず、次のターンにその属性のレベルが1上昇する。

最大レベルは `Lv3`。

例:

```text
ターン1

FIRE   Lv1  ← 使用
STONE  Lv1
MIST   Lv1
```

次のターン:

```text
FIRE   Lv2
STONE  Lv1
MIST   Lv1
```

さらにFIREを使用すると:

```text
FIRE   Lv3
STONE  Lv1
MIST   Lv1
```

### 4.3 Lv3の維持

Lv3になった属性を使用せず、別の属性を選択した場合はLv3のまま保持する。

例:

```text
FIRE   Lv3
STONE  Lv1
MIST   Lv1
```

STONEを使用した場合:

```text
FIRE   Lv3
STONE  Lv2
MIST   Lv1
```

### 4.4 Lv3使用後の処理

Lv3の属性を使用した場合、勝利・敗北なら使用した属性は `Lv0` になる。あいこなら `Lv3` のまま維持する。

STAGE 04の敵は、残りHPが50以下になったターンの終了時に全属性が `Lv3` になり、以降も `Lv3` を維持する。封印中の属性は、封印が解除されるまで使用できない。

必殺効果が発動するのは勝利した場合のみとする。

```text
勝利
→ 必殺効果発動
→ 使用した属性はLv0

敗北
→ 必殺効果不発
→ 使用した属性はLv0

あいこ
→ 必殺効果不発
→ 使用した属性はLv3のまま
```
### 4.5 Lv0


Lv0の属性は使用できなくなる。

例:

```text
FIRE   Lv0  ← 使用不可
STONE  Lv1
MIST   Lv1
```

#### 4.5.1 Lv0からの復活

Lv0になった後、別の属性を1回使用すると、勝敗にかかわらず、Lv0だった属性は次のターンに `Lv1` へ復活する。

例:

```text
FIRE   Lv0
STONE  Lv1  ← 使用
MIST   Lv1
```

次のターン:

```text
FIRE   Lv1  ← 復活
STONE  Lv2
MIST   Lv1
```

そのため、Lv0は実質的に「1ターン使用不能」の状態となる。

## 5. ダメージ・必殺技

### 5.1 通常ダメージ

| レベル | 基本ダメージ |
|---|---:|
| Lv1 | 10 |
| Lv2 | 20 |
| Lv3 | 属性固有の必殺技 |

Lv1・Lv2ではFIRE / STONE / MISTすべて同じダメージ量とする。

### 5.2 Lv3 必殺技

Lv3では属性ごとに異なる効果を持つ。

#### 5.2.1 FIRE Lv3

**役割: 攻撃**

```text
ダメージ: 50
```

通常攻撃より大きなダメージを与える。

イメージ:

> 松明の炎が一気に燃え上がり、相手を焼き払う。

---

#### 5.2.2 STONE Lv3

**役割: 防御**

```text
ダメージ: 30
+
次に受けるダメージを50%軽減
```

防御効果は、ダメージを受けるまで持続する。あいこのダメージにも適用し、1回半減した時点で効果を解除する。効果は重複しない。

例:

次にFIRE Lv3の50ダメージを受ける場合:

```text
50 × 0.5 = 25ダメージ
```

Lv1の10ダメージを受ける場合:

```text
10 × 0.5 = 5ダメージ
```

イメージ:

> 石の加護が身体を覆い、次の攻撃を受け止める。

---

#### 5.2.3 MIST Lv3

**役割: 妨害**

```text
ダメージ: 20
+
相手のFIRE / STONE / MISTから
ランダムで1属性を次のターン封印
```

封印する属性は、相手の属性レベルや使用可否にかかわらず、3属性から同じ確率で抽選する。

```text
FIREが選ばれる確率: 1/3
STONEが選ばれる確率: 1/3
MISTが選ばれる確率: 1/3
```

Lv0の属性も抽選対象に含める。
抽選された属性がすでにLv0で使用できない場合も、抽選をやり直さない。

封印された属性は次のターンのみ使用できず、そのターン終了時に封印が解除される。解除時、封印されていた属性のレベルを1上げる。ただし上限はLv3とし、Lv3はそのまま維持する。Lv0が封印されていた場合は、通常の復活でLv1になった後、封印解除によってLv2になる。

例:

FIREが抽選された場合:

```text
次のターン
FIRE → 使用不可
```

イメージ:

> 白い霧が相手の力を包み込み、その属性を一時的に封じる。

### 5.3 MISTのランダム封印とLv0の関係

Lv0の復活処理とMISTの封印は別々に扱う。封印されたターンの終了時は、通常のLv0復活処理を行ってから封印を解除し、その属性のレベルを1上げる。封印解除によるレベルアップはLv3を上限とする。

| 封印中のレベル | 封印解除後のレベル |
|---|---|
| Lv0 | Lv2（通常復活のLv1からさらに1上昇） |
| Lv1 | Lv2 |
| Lv2 | Lv3 |
| Lv3 | Lv3 |

例えば相手が以下の状態だったとする。

```text
FIRE   Lv2
STONE  Lv3
MIST   Lv2
```

相手がSTONE Lv3を使用し、MIST Lv3に負けた場合、勝敗の判定後にMISTの効果によって相手の3属性から1つをランダムで封印する。
その後、相手が使用したSTONEをLv0にする。

FIREが抽選された場合:

```text
FIRE   封印 ← 使用不可
STONE  Lv0  ← 使用不可
MIST   Lv2  ← 使用可能
```

相手は次のターン、MISTのみ使用できる。

STONEが抽選された場合:

```text
FIRE   Lv2  ← 使用可能
STONE  Lv0  + 封印 ← 使用不可
MIST   Lv2  ← 使用可能
```

STONEはすでにLv0のため、封印によって使用不能な属性は増えない。
次のターンに相手がFIREかMISTを使用すると、STONEは通常復活と封印解除を経てLv2になる。

MISTが抽選された場合:

```text
FIRE   Lv2  ← 使用可能
STONE  Lv0  ← 使用不可
MIST   封印 ← 使用不可
```

相手は次のターン、FIREのみ使用できる。

### 5.4 ダメージ・特殊効果一覧

| 属性 | Lv1 | Lv2 | Lv3 |
|---|---:|---:|---|
| FIRE | 10ダメージ | 20ダメージ | **50ダメージ** |
| STONE | 10ダメージ | 20ダメージ | **30ダメージ + 次に受けるダメージを50%軽減** |
| MIST | 10ダメージ | 20ダメージ | **20ダメージ + 相手の3属性からランダムで1属性を次ターン封印** |

## 6. UI仕様

### 6.1 コンポーネント構成

KETRIA専用のSvelteコンポーネントは、`src/lib/ketria/components` に配置する。

Atomic Designを基準として、コンポーネントを `atoms`、`molecules`、`organisms` の3階層に分ける。

```text
src/lib/ketria/components/
├── atoms/
├── molecules/
└── organisms/
```

### 6.2 表示情報

プレイヤー・敵それぞれについて以下を表示する。

```text
HP

FIRE   Lv?
STONE  Lv?
MIST   Lv?
```

例:

```text
PLAYER
HP 160 / 200

🔥 FIRE   Lv3
◆ STONE  Lv2
〰 MIST   Lv1
```

Lv0・封印中については明確に判別できるUIにする。

例:

```text
🔥 FIRE   Lv0     [LOCKED]
◆ STONE  Lv2
〰 MIST   Lv1
```

MISTによる封印の場合:

```text
🔥 FIRE   Lv1
◆ STONE  Lv3     [SEALED]
〰 MIST   Lv2
```
