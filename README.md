# KeveltKit

KeveltKit は、SvelteKit × TypeScript をベースに開発しました。

シンプルなデザインと設計を軸に、ストレスなく閲覧できるサイトを目指しています。

---

## Tech Stack

### Frontend

- SvelteKit
- TypeScript
- Vanilla Extract
- mdsvex

### Testing

- Vitest
- @testing-library/svelte
- Playwright

### Other

- Vite
- Prettier
